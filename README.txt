ÓRDENES DE CARGUE — APP MÓVIL

Esta versión convierte la página en una PWA instalable y con funcionamiento offline.

INSTALACIÓN EN ANDROID (GRATIS)
1. Sube esta carpeta a un hosting HTTPS gratuito (por ejemplo GitHub Pages, Netlify o Cloudflare Pages).
2. Abre la dirección desde Chrome en Android.
3. Pulsa “INSTALAR APP” cuando aparezca, o usa el menú de Chrome > “Instalar aplicación”.
4. La app queda en la pantalla de inicio y conserva los registros en el mismo dispositivo mediante almacenamiento local.

IMPORTANTE
Los datos de esta página se guardan localmente en el dispositivo. Si borras los datos del navegador o cambias de dispositivo, los registros no se transfieren automáticamente.
